# 补货预测异常识别
# Replenishment-anomaly-detector
识别降级误补货、退货异常和偶发大单

这是一个 Streamlit 工具。上传两行表头的补货预测 `.xlsx` 后，工具会：

- 自动识别“实际销量”中的 13 个自然月，排除最后一个未完结当前月；
- 识别 A/B 降级至 C 后可能产生的错误补货；
- 比较不含退货月与含退货月的库存覆盖时间，识别退货扭曲造成的缺货风险；
- 使用对数 MAD 稳健阈值识别疑似偶发性大单；
- 侧边栏按“总览 → 细分分析”分层：异常清单汇总包含三个细分页面的全部记录；
- 导出全中文的汇总及四个分析工作表。

## 启动

```powershell
python -m pip install -r requirements.txt
py -m streamlit run app.py
```

## 默认计算口径

- 有效库存：`非限制库存 + 在途 + 在产`，可在侧边栏切换。
- C Level（PC/RC）：`0.6 × 最近 1–6 月平均 + 0.4 × 最近 7–12 月平均`。
- 其他等级：`0.6 × 最近 1–3 月平均 + 0.4 × 最近 4–6 月平均`。
- Target MOS 优先使用上传文件中的“库存月数”，缺失时按等级映射。
- 降级误补货页面同时显示 `MAX(0, 6 × A/B级预测月销量 − 当前库存)` 和 `MAX(0, 3 × C级预测月销量 − 当前库存)`。
- 偶发大单使用现有的全部历史正销量；少于3个月时跳过自动判断。
- 退货影响时间按预测窗口计算：A/B级为6个月，C级为12个月。
- 仅当实际库存可用月数小于退货影响时间，且小于理论库存可用月数时，判定会引起断货。
- 断货月数为 `min(退货影响时间, 理论库存可用月数) - 实际库存可用月数`，不小于0。

退货基线会从对应加权窗口中剔除负销量，不会将估计的销量扭曲量再次加到当前库存中。退货异常判定不使用海运时间。

## 代码结构

- `downgrade_misreplenishment.py`：`DowngradeMisreplenishmentAnalyzer`，负责降级误补货规则。
- `return_anomaly.py`：`ReturnAnomalyAnalyzer`，负责退货异常、库存覆盖及断货判断。
- `oneoff_order_analysis.py`：`OneOffOrderAnalyzer`，负责偶发大单的稳健统计判断。
- `forecast_analyzer.py`：读取源文件、调用三个分析器、汇总结果并生成中文页面和 Excel 输出。
