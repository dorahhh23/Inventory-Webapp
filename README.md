# 补货预测与库存结构分析

这是一个基于 Streamlit 的补货预测分析工具，包含两个独立的一级页面：

- **补货预测异常识别**：识别降级误补货、退货异常和疑似偶发性大单。
- **库存结构分析**：结合 Replenishment 表与价格表，分析库存覆盖、库存金额和产品结构。

## 启动

```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

启动后，通过左侧的“一级页面”切换两个分析模块。

## 补货预测异常识别

### 输入文件

上传一个采用两行表头的 Replenishment `.xlsx` 文件：

- 第一行为字段分组；
- 第二行为具体字段名；
- 系统按字段名称识别数据，不依赖固定列号。

### 分析内容

#### 降级误补货问题

适用于上一季度为 A/B 级、本季度降为 C 级的产品。系统比较两种等级对应的预测月销量和预测补货量，用于识别因历史窗口从 6 个月扩大到 12 个月而产生的误补货风险。

- C Level（PC/RC）：`0.6 × 最近1–6月平均 + 0.4 × 最近7–12月平均`
- 其他等级：`0.6 × 最近1–3月平均 + 0.4 × 最近4–6月平均`
- A/B 级预测补货量：`MAX(0, 6 × A/B级预测月销量 − 当前库存)`
- C 级预测补货量：`MAX(0, 3 × C级预测月销量 − 当前库存)`

#### 退货异常问题

检查最近一个完整月份是否发生大额退货或冲销，导致预测销量远低于实际销售水平并产生缺货风险。

- 退货基线会从对应的加权窗口中剔除负销量；
- A/B 级退货影响时间为 6 个月，C 级为 12 个月；
- 只有实际库存可用月数同时小于退货影响时间和理论库存可用月数时，才判定会引起断货；
- 断货月数：`MAX(0, MIN(退货影响时间, 理论库存可用月数) − 实际库存可用月数)`；
- 判定不考虑海运时间，也不会把估计的销量扭曲量重复加回库存。

#### 偶发大单分析

使用现有的全部历史正销量和对数 MAD 稳健阈值，判断最近一个完整月份是否为疑似偶发性大单。可用正销量历史少于 3 个月时跳过自动判断。

### 页面和导出

- 一级 Tab“异常清单汇总”包含三个问题的全部异常记录；
- 一级 Tab“细分清单”下包含三个问题的独立 Tab；
- 退货异常记录按断货风险和断货时长优先展示；
- 可下载包含中文字段、问题说明和格式强调的 Excel 分析结果。

## 库存结构分析

### 输入文件

需要同时上传两个 `.xlsx` 文件。

#### Replenishment 表

采用与异常分析相同的两行表头。系统自动识别：

- 销售组织、物料、物料描述；
- 产品状态、产品组、产品组描述；
- 优先识别“国贸产品分类码”；该字段不存在时，自动识别并分别使用“国贸产品分类码L1”至“国贸产品分类码L4”；
- 级别、当前库存等级、库存月数；
- 当前可用库存、在途+在产；
- 月预测、月预测（修改）；
- “全供应链存销比”为可选源字段；分析结果统一按 `(当前可用库存 + 在途+在产) ÷ 有效预测月销` 重新计算，任一必要数值缺失或有效预测月销不大于 0 时留空。

库存结构分析仅纳入“级别”为 `Parent` 的记录。比较时忽略大小写和首尾空格；`Son`、空值及其他级别不会进入计算、汇总、图表或导出结果。

#### 价格表

价格表至少需要物料代码列和单价列。系统会尝试自动识别价格列，但自动识别后仍会弹出确认窗口，只有用户确认后才开始计算。识别错误或无法识别时，必须手动选择价格列；系统不会默认使用其他字段代替价格。

- 通过物料代码与 Replenishment 表关联；
- 同一物料的重复价格一致时自动去重；
- 重复价格不一致时标记为“价格冲突”，不静默选取其中一条；
- 找不到价格时标记为“价格缺失”，单价和库存金额留空；
- 缺失价格不会被当作 0，但对应物料仍计入型号数量。

### 计算口径

#### 有效预测月销

1. “月预测（修改）”为有效数字时优先使用；
2. 否则使用“月预测”。

#### 可用库存存销比

```text
可用库存存销比 = 当前可用库存 ÷ 有效预测月销
```

单位为月，页面和 Excel 显示两位小数。缺失值不会自动按 0 处理。

#### 可用库存金额

```text
可用库存金额 = 当前可用库存 × 单价
```

- 明细表保留原始美元金额；
- 库存结构概要和三个汇总分析统一使用百万美元口径；
- 汇总表及汇总图中的金额列名称为“可用库存金额（M USD）”。

### 库存区间

三个区间互斥：

| 库存区间 | 判定条件 |
| --- | --- |
| 库存24个月以上 | 可用库存存销比 ≥ 24个月 |
| 超目标库存 | 目标库存月数 + 3 < 可用库存存销比 < 24个月 |
| 正常及关注库存 | 可用库存存销比 ≤ 目标库存月数 + 3 |

等于 24 个月时归入“库存24个月以上”；等于“目标库存月数 + 3”时归入“正常及关注库存”。

以下记录标记为“数据问题”，不强行划入可正常计算的库存区间，并显示在“正常及关注库存”明细的最后：

- 有效预测月销缺失；
- 有效预测月销小于或等于 0；
- 当前可用库存缺失；
- 存销比低于 24 个月，但目标库存月数缺失。

价格缺失或价格冲突只影响库存金额；只要存销比可以计算，仍可正常划分库存区间。

### 页面布局

页面依次显示：

1. Replenishment 表和价格表上传区域；
2. 字段识别、价格字段选择和计算状态；
3. 库存结构概要；
4. 三个库存区间明细 Tab，明细表默认折叠；
5. Product Status、Product Group、国贸产品分类码三个汇总 Tab；
6. Excel 下载按钮。

库存结构概要分为两行：

- 第一行：物料总数、可用库存金额（百万美元）；
- 第二行：库存24个月以上、超目标库存、正常及关注库存、数据问题。

### 汇总分析

提供三个汇总维度：

- Product Status：使用“产品状态”；
- Product Group：保留产品组代码，使用产品组描述作为显示名称；
- 国贸产品分类码：优先使用原“国贸产品分类码”；缺失时按实际存在的 L1–L4 分别汇总，并在页面中显示为独立层级 Tab。L1 直接展示所有分类的汇总表、柱状图和饼图；L2–L4 展示累计贡献前 80% 库存金额的分类表和透视图，不再使用 1 M USD 金额分层。所有层级均显示分组总数。

每个汇总均：

- 按可用库存金额从高到低排列；
- 显示可用库存金额（M USD）、占总库存金额的比例和去重后的型号数量；
- 包含合计行；
- 缺失分类统一显示为“未分类”；
- 同时显示汇总表和库存金额图表。Product Status 保留完整饼图；Product Group 环形图按占比自适应标注，占比达到 5% 的分类在扇区内显示名称和占比，较小分类不显示外侧引导线，统一通过右侧图例查看名称和占比。

国贸产品分类码采用两个 Tab：

1. **库存分类概览**：按核心（≥1 M USD）、重点（0.5–1 M USD）、一般（0.1–0.5 M USD）、长尾（0–0.1 M USD）和负金额分层，展示分类码数量、型号数量、库存金额、占比和单型号平均金额；表格下方提供双轴透视图。网页使用横向金额柱形和独立的型号数量点，自动隐藏完全无数据的层级，柱形自适应显示金额和占比，负金额向左展示；
2. **数据明细**：合并原“重点分类码”和“全部明细及数据问题”，按库存金额从高到低显示所有分类码，并增加“库存分层分类”列。金额缺失不强行分层，通过“数据状态”标记。

原“国贸产品分类码”明细表继续提供库存分层分类；L2–L4 明细表提供排名、累计占比、数据状态和单型号库存金额，不再添加 1 M USD 库存分层。

### Excel 导出

存在原“国贸产品分类码”时，库存结构分析结果包含七个工作表：

1. 库存24个月以上；
2. 超目标库存；
3. 正常及关注库存；
4. 按产品状态汇总；
5. 按产品组汇总；
6. 国贸分类码分层；
7. 按国贸分类码汇总。

原字段不存在时，第 6、7 个工作表会改为按实际识别到的 L1–L4 动态生成。L1 仅生成“国贸分类码L1汇总”，并包含柱状图和饼图；L2–L4 只生成各自的“明细”工作表，每张明细表同时包含累计前80%分类透视图和累计占比图。同时存在 L1–L4 时，总计九个工作表。

导出文件包含冻结表头、筛选、隐藏网格线、中文表头、合理列宽和数值格式。前三个库存区间明细工作表以“销售组织”为首列；所有导出图表的宽度和高度均按原尺寸的三分之二显示。国贸分类码概览工作表包含一张分层透视图，柱形标签显示库存金额占比；国贸分类码只导出一张按库存金额排序的明细表，数据问题使用浅黄色强调，负库存金额使用浅红色强调。所有汇总与国贸分类码分析工作表的库存金额单位均为 `M USD`，三个库存区间明细工作表保留原始美元金额。

## 代码结构

- `app.py`：Streamlit 页面布局、文件上传、分析器调用、结果展示和下载入口。
- `forecast_analyzer.py`：异常分析源文件读取、三个异常分析器调用、结果汇总和 Excel 输出。
- `downgrade_misreplenishment.py`：`DowngradeMisreplenishmentAnalyzer`，负责降级误补货规则。
- `return_anomaly.py`：`ReturnAnomalyAnalyzer`，负责退货异常、库存覆盖和断货判断。
- `oneoff_order_analysis.py`：`OneOffOrderAnalyzer`，负责偶发大单判断。
- `inventory_structure_analysis.py`：`InventoryStructureAnalyzer`，负责库存字段识别、Parent 筛选、价格关联、库存分类、汇总、数据检查和 Excel 输出。
- `tests/test_forecast_analyzer.py`：补货预测异常分析测试。
- `tests/test_inventory_structure_analysis.py`：库存结构分析和 Excel 导出测试。
